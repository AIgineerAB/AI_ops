# AIOps

In this course, you'll dive into working with LLMs and LLMOps including

- Vector database
- RAG
- Evaluation
- LLM judge
- Hallucination detection
- Tracing
- Moniitoring
- Prompt management and optimization
- Deployment
- CI/CD
- MCP

For this you will be using the following tools:

- PydanticAI
- LanceDB
- FastAPI
- Logfire
- Azure
- Docker
- Github Actions
- pymcp
