## Setup 

Create a free account in [FireCrawl](https://www.firecrawl.dev/). 

Install firecrawl to your venv 

```py 
uv add firecrawl
```

Place your API in `.env` 

```env
FIRECRAWL_API_KEY=
```

By calling it exactly that, firecrawl will automatically load it.
